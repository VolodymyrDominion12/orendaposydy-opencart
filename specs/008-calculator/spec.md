## Проблема
1. Організаторам заходів та приватним замовникам важко розрахувати точну кількість посуду під формат свята (банкет, фуршет чи кава-брейк). Без знання ресторанних норм виникає або нестача тарілок/келихів під час події, або перевитрата бюджету на зайвий інвентар.
2. Ручний підбір та калькуляція по десятках категорій забирає багато часу, відлякує клієнтів і змушує відкладати замовлення.
3. Потрібен простий інтерактивний інструмент, який за 10 секунд генерує повний кошторис на будь-яку кількість гостей (10–300) із запасом 10% і дає змогу одразу або покласти все в кошик, або відправити запит менеджеру для узгодження.

## Мета і метрика
- Надати клієнту миттєвий автоматичний розрахунок посуду, приборів і скла під будь-який формат заходу:
  - Кількість гостей: 10–300 (інтерактивний повзунок / числовий інпут).
  - Формат події: **Банкет** (повноцінне застілля), **Фуршет** (вільний стіл), **Кава-брейк** (легкі закуски та напої).
  - Кількість страв: 2, 3, 4+ (коригує норми закусочних та обідніх тарілок і приборів).
  - Напої: вино, шампанське, міцні напої (додають відповідні типи скла: келихи, флюте, чарки).
  - Серія посуду: **Classic** (біла порцеляна, сталеві прибори) або **Royal** (посуд із золотим обідком, золоті прибори).
- **Динамічні ціни з каталогу:** ціни позицій беруться з актуальної БД `oc_product`.
- **Запас 10% та пакування:** кількість автоматично рахується за формулою `Math.ceil(guests * norm * 1.1 / pack_size) * pack_size` (де `pack_size` — розмір упаковки / мінімальний крок).
- **Дві цільові дії:**
  1. «Все в кошик» — пакетне додавання всього розрахованого комплекту до кошика замовлення (`cart`/`checkout/order`).
  2. «Надіслати менеджеру» — автозаповнення форми ліда `kristal_lead` параметрами розрахунку та швидка відправка.
- **Адміністрування норм:** таблиця `oc_kristal_calc_norm` з можливістю редагування норм на гостя, прив'язки товарів та розмірів пакування в адмінпанелі.

## Критерії приймання

### AC-1. База даних норм калькулятора
- Таблиця `oc_kristal_calc_norm`:
  - `norm_id` INT AUTO_INCREMENT PRIMARY KEY;
  - `category_type` VARCHAR(32) NOT NULL ('plates', 'cutlery', 'glass');
  - `name` VARCHAR(128) NOT NULL (назва позиції у розрахунку);
  - `product_id_classic` INT UNSIGNED NOT NULL;
  - `product_id_royal` INT UNSIGNED NOT NULL;
  - `norm_banquet` DECIMAL(5,2) NOT NULL DEFAULT 0.00;
  - `norm_buffet` DECIMAL(5,2) NOT NULL DEFAULT 0.00;
  - `norm_coffee` DECIMAL(5,2) NOT NULL DEFAULT 0.00;
  - `dish_rule` VARCHAR(32) NULL (напр. 'extra_if_4_dishes', 'skip_if_2_dishes');
  - `drink_filter` VARCHAR(32) NULL ('wine', 'champ', 'strong' або NULL для обов'язкових);
  - `pack_size` INT UNSIGNED NOT NULL DEFAULT 10;
  - `sort_order` INT NOT NULL DEFAULT 0;
  - `status` TINYINT(1) NOT NULL DEFAULT 1.
- SEO URL:
  - `extension/kristal/calculator` -> `kalkulyator`.

### AC-2. Сторінка калькулятора (вітрина)
- Доступна за ЧПУ `/kalkulyator`.
- Заголовок H1, breadcrumbs, мета-теги, опис.
- Повзунок гостей: значення від 10 до 300 із кроком 5 (значення синхронізується з числовим дисплеєм).
- Перемикачі формату події (Банкет / Фуршет / Кава-брейк).
- Перемикачі кількості страв (2 / 3 / 4+).
- Чекбокси напоїв (Вино, Шампанське, Міцні напої).
- Випадаючий список серії (Classic / Royal).
- Реактивна таблиця результатів:
  - Групування: «Посуд», «Столові прибори», «Скло та келихи».
  - Колонки: Позиція (посилання на товар), К-сть, Ціна/добу, Сума.
  - Підсумок: Загальна сума за добу, орієнтовна сума на одного гостя (`≈ X ₴ за гостя · з запасом 10%`).
- Мобільна оптимізація: ширина від 360px без горизонтального скролу, тач-таргети мінімум 44×44px.

### AC-3. Дія «Все в кошик»
- AJAX-запит на `index.php?route=extension/kristal/calculator/add`:
  - Передає параметри або список розрахованих позицій з кількостями.
  - Сервер валідує актуальні ціни та додає всі товари в сесійний кошик `cart`.
  - Повертає статус успіху, оновлену кількість товарів у шапці/таббарі.
  - Клієнт показує зворотний зв'язок (індикатор/повідомлення) і перенаправляє до кошика або оновлює лічильник.

### AC-4. Дія «Надіслати менеджеру»
- Скрол до форми ліда `#lead` або передача параметрів розрахунку.
- Автозаповнення полів форми:
  - Кількість гостей.
  - Приховане або коментарне поле з деталями розрахунку (формат, серія, сума за добу, перелік позицій).
- Успішна інтеграція з `kristal_lead` (009).

### AC-5. Панель керування (адмінка)
- Пункт меню «Каталог → Норми калькулятора» (`extension/kristal/calculator`).
- Список норм із фільтрацією за категорією/форматом.
- Форма редагування: назва, категорія, товари серій Classic/Royal, коефіцієнти для банкету/фуршету/кава-брейку, правила для страв та напоїв, крок пакування.
- Валідація прав доступу `modify`.
