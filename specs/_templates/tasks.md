# NNN — Задачі

Кожен крок ≤ ~1 год. Відмічай `- [x]` одразу після перевірки.

## Реалізація
- [ ] **T1.** <що зробити> — *перевірка:* <команда або дія → очікуваний результат>
- [ ] **T2.** ...

## Перевірки (DoD)
- [ ] `make lint` — 
- [ ] `make db-check` — 
- [ ] `make db-schema-diff` / `make db-schema-snapshot` — 
- [ ] `make db-profile URL=...` до → після: 
- [ ] `make test-smoke` — 
- [ ] `make test-mobile` (LCP / CLS / вага до → після): 
- [ ] Реальний телефон (Android + iPhone): 
- [ ] `make logs-php` без Notice/Warning —
