# ProductCard

Картка позиції в каталозі: фото, категорія, назва, артикул і кількість, ціна оренди та дія.

Структура: `.kr-card` → `.kr-card__media` (фото 4:3 на `night-sunken`, необов'язковий бейдж) → `.kr-card__body` (`__cat`, `__name`, `__meta`, `__foot` з `.kr-price` і кнопкою).

- Фото — на темному тлі, без білого фону.
- Ціна — `kr-price`, формат `12 ₴` + `<small>/ доба</small>`.
- Артикул і доступна кількість — моно (`__meta`): «Арт. GL-0451 · 120 шт».
- При наведенні межа стає `gold-deep` і з'являється `shadow-card`.
- Сітка карток — `kr-grid`, проміжок `space-6`.

Споживач передає фото (`<img>` у `__media`), назву, категорію, артикул, кількість, ціну.
