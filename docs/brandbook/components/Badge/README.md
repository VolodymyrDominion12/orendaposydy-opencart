# Badge

Одне-два слова статусу на картці товару або в кошику.

| Варіант | Клас | Значення |
|---|---|---|
| Хіт | `kr-badge kr-badge--hit` | Найпопулярніші позиції. Рубін — урочистий, не тривожний. |
| Новинка | `kr-badge kr-badge--new` | Нове в асортименті. |
| В наявності | `kr-badge kr-badge--stock` | Є на обрану дату. |
| Немає на дату | `kr-badge kr-badge--none` | Зайнято на обрану дату. |
| Під замовлення | `kr-badge kr-badge--muted` | Привеземо від партнерів, 2–3 дні. |

Не більше одного бейджа на картку. Текст великими літерами, до двох слів.
