# Button

Кнопки дій: одна золота головна на екран, решта — контурні.

| Варіант | Клас | Коли |
|---|---|---|
| Головна | `kr-btn kr-btn--primary` | «Забронювати», «Додати в замовлення». Одна на екран. |
| Другорядна | `kr-btn kr-btn--secondary` | «Розрахувати вартість», «Каталог». |
| Тиха | `kr-btn kr-btn--ghost` | «Скасувати», «Назад», фільтри. |

- Кути гострі (`radius-none`) — як у гербі.
- Текст на головній — `on-gold`, ніколи білий.
- При наведенні головна загоряється `shadow-glow` — це єдине сяйво на екрані.
- Підпис — дієслово, що описує результат: «Забронювати на 14 червня», а не «Відправити».

Споживач підключає `components/bundle.css` і токени; React не потрібен.
