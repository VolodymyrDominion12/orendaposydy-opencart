# Носії

## Сайт

- Шапка й основне тло — `night`. Зліва емблема (мінімум 48 px) + напис «КРІСТАЛ» Forum, золото. Меню — Manrope 500, активний пункт підкреслено лінією `gold` 2 px.
- Головний екран: повна емблема зі сяйвом, заголовок Forum `display-xl`, одне слово золотом, одна головна кнопка `gold`.
- Каталог: сітка карток `ProductCard`, проміжок `space-6`. Ціна — золота, моно. Плашка «Хіт» — `ruby`.
- Футер — `night-sunken`, контакти великим шрифтом: **+38 067 827 70 07**, м. Львів, вул. Богдана Хмельницького, 106.

## Соцмережі

- Аватар — знак-мінімум (літера з короною) на `night`.
- Пости: фото на темному тлі, заголовок Forum, золота рамка навколо кадру для святкових добірок.
- Акції: тло `ruby-deep`, текст `gold` — як поле й обідок емблеми.

## Документи та рахунки

Світла тема: тло біле, емблема в плоскій версії або напис «КРІСТАЛ» Forum кольору `gold-deep`. Таблиці з лініями `line`, ціни — JetBrains Mono. Угорі аркуша — тонка смуга `gold` 4 px.

## Ящики, наклейки, транспорт

- Ящики для посуду: наклейка з плоскою емблемою на `night` + артикул JetBrains Mono.
- Автомобіль: чорний або графітовий кузов, велика плоска емблема, напис «КРІСТАЛ» і телефон золотом.

## Форма персоналу

Чорний верх, маленька вишита емблема (плоска версія) на грудях зліва, нитка золото. Персонал на події має бути непомітним.
