# Контент-пак для показу клієнту (2026-11-11)

Мета: показати клієнту `orendaposudu.com` у вигляді, близькому до макетів `design/`:
нова структура каталогу, назви й SEO-описи категорій, ціни за добу, умови оренди,
тексти головної та контакти. **Правильність цін/цифр не остаточна** — клієнт
замінить реальними даними.

## Що змінюється

| Що | Де | Примітка |

| 11 верхніх категорій + підкатегорії | `oc_category`, `oc_category_description`, `oc_category_path` | як у `design/pages/01-home.html` |
| SEO `title`, `meta description`, SEO-текст | `oc_category_description` | 33 увімкнені категорії |
| Товари в категоріях | `oc_product_to_category` | 49 товарів, дерево з батьками |
| Ціни за добу, мін. кількість | `oc_product`, `oc_product_discount` | ціни-заглушки |

| Фільтри «Матеріал», «Колір» | `oc_filter*`, `oc_product_filter` | 98 зв'язок |
| ЧПУ 7 товарів без адреси | `oc_seo_url` | |
| Тексти головної + контакти | `oc_setting` (`module_kristal_home_*`, `module_kristal_core_*`) | телефон, Viber, адреса, графік, email |
| 301 зі старих адрес | `oc_kristal_redirect` | 6 нових правил |

## Як застосувати

1. **Бекап:** phpMyAdmin на хостингу → база → **Експорт** → Go. Зберегти файл.
2. **SQL:** phpMyAdmin → база → **SQL** → вставити вміст
   `backups/for-phpmyadmin-prod-content-demo-20261111-*.sql` (або «Імпорт» цим файлом) → Go.
3. **Кеш:** Адмінка → шестерня вгорі праворуч → **Оновити**.
   (Кеш `kristal.*` живе 1 годину, тож без цього зміни можуть з'явитися не одразу.)
4. Перевірити `/`, `/posud`, `/posud/tarilky`, `/mebli`, `/tarilky-26-26-sm`.

Відкат: імпорт зробленого на кроці 1 експорту.

Файл ідемпотентний — повторний запуск не створює дублів.

## Порожні категорії

`Кухонне обладнання`, `Барне обладнання`, `Меблі`, `Текстиль`, `Шатри та накриття`
показані в меню й на головній, але товарів у них поки немає — сторінка з SEO-текстом
і повідомленням «У цьому розділі поки немає товарів». Це навмисно, щоб клієнт бачив
структуру; після додавання товарів блоки заповняться.

## Відомі обмеження (не входили в пакет)

- Блоки головної з макета «швидкий підбір», «події», «комплекти», «портфоліо»,
  «відгуки» в темі ще не зверстані — це окрема задача (004/006/007/014).
- `rel="canonical"` підкатегорій береться з ядра за останнім ID і втрачає шлях
  (`/tarilky` замість `/posud/tarilky`) — виправити в темі/OCMOD (011).
- Фотознімання складу й подій — від клієнта.
