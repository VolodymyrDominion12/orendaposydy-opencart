# Чек-лист: мобільна оптимізація

Більшість відвідувачів сайту оренди заходять із телефону: шукають «оренда посуду Львів», дивляться ціну й одразу дзвонять або пишуть у Viber. Тому мобільна версія — основна. Десктоп — розширення мобільної, а не навпаки.

## Бюджети (`tests/mobile/budgets.json`, перевіряє `make test-mobile`)

Емуляція як у Lighthouse mobile: 360×640, DPR 3, повільний 4G (RTT 150 мс, 1.6 Мбіт/с), процесор у 4 рази повільніший.

| Метрика | Бюджет | Чому |
|---|---|---|
| LCP | ≤ 2.5 с | поріг «добре» Core Web Vitals; впливає на ранжування в Google |
| CLS | ≤ 0.1 | макет не стрибає, клієнт не тисне «не туди» |
| TBT (лабораторний замінник INP) | ≤ 300 мс | сторінка реагує на дотик |
| Вага сторінки | ≤ 1200 КБ | на мобільному інтернеті за містом |
| JS / CSS / шрифти / зображення | ≤ 250 / 80 / 120 / 700 КБ | |
| Запитів | ≤ 50 | |
| Горизонтальний скрол на 360px | 0 елементів | |
| Клікабельні зони < 44×44 | 0 | палець, а не курсор |
| Текст < 12px | 0 | читається без збільшення |
| `<img>` без `width`/`height`, не-lazy нижче екрана, завеликі, JPEG/PNG > 20 КБ | 0 | |
| Масштабування заборонене (`user-scalable=no`, `maximum-scale=1`) | 0 | доступність |
| Поле телефону не `type="tel"` | 0 | цифрова клавіатура |

Бюджет змінюється лише з поясненням у `plan.md` фічі й погодженням людини.

## Верстка

- [ ] Mobile-first CSS: базові стилі для 360px, розширення через `@media (min-width: …)`. Брейкпоінти: 360, 768, 1024, 1280.
- [ ] Перевірка на 360px (найменший поширений Android) і 375px (iPhone): немає горизонтального скролу, нічого не обрізано.
- [ ] Тач-зони ≥ 44×44 px, відстань між сусідніми ≥ 8 px. Кнопки кількості «−/+» у кошику теж.
- [ ] Основний текст ≥ 16px (інакше iOS збільшує сторінку при фокусі на полі), другорядний ≥ 13px, мінімум 12px.
- [ ] Головна дія досяжна великим пальцем: нижня мобільна панель «Каталог · Дзвінок · Viber · Кошик» (концепція), `position: fixed`, з `padding-bottom: env(safe-area-inset-bottom)`.
- [ ] Телефон — `<a href="tel:+380…">`, Viber/Telegram — прямі посилання; на мобільному показуються першими.
- [ ] Меню — повноекранне, закривається жестом/кнопкою, блокує прокрутку фону, розміри пунктів ≥ 48px.
- [ ] Фільтри каталогу — у нижній шторці з кнопкою «Показати N товарів», а не в лівій колонці.
- [ ] Таблиці (знижки за обсяг, характеристики) — картками або з горизонтальною прокруткою всередині блоку, не всієї сторінки.
- [ ] Ніяких hover-only дій: усе, що на десктопі з'являється при наведенні, на мобільному доступне дотиком.

## Форми (заявка, калькулятор, оформлення)

- [ ] Мінімум полів: ім'я, телефон, дата події, кількість гостей; решта — необов'язкова.
- [ ] Телефон `type="tel" inputmode="tel" autocomplete="tel"`, ім'я `autocomplete="name"`, email `type="email"`, кількість `inputmode="numeric"`, дата — нативний `type="date"`.
- [ ] Підпис над полем (не placeholder замість підпису), помилки під полем, текст помилки зрозумілий.
- [ ] Кнопка відправки на всю ширину, ≥ 48px, не ховається під клавіатуру.

## Зображення

- [ ] WebP (або AVIF) з запасним JPEG лише для старих браузерів: `<picture>`.
- [ ] `srcset` + `sizes`: мобільному не віддаємо картинку на 1200px. Розміри прев'ю в налаштуваннях теми OpenCart під реальні розміри карток.
- [ ] `width` і `height` на кожному `<img>` (або `aspect-ratio` у CSS) — без стрибків макета.
- [ ] `loading="lazy"` для всього нижче першого екрана; головне зображення першого екрана (LCP) — **без** lazy, з `fetchpriority="high"`, і `<link rel="preload">` при потребі.
- [ ] Іконки — SVG-спрайт або інлайн-SVG, не іконковий шрифт.

## CSS, JS, шрифти

- [ ] Критичний CSS першого екрана — інлайн у `<head>`, решта — асинхронно; невикористаний CSS шаблону видалено.
- [ ] JS з `defer`; без jQuery-плагінів для того, що робиться 20 рядками ванільного JS (тема `kristal`). Сторонні віджети (чат, карта, відгуки) — відкладене завантаження після першої взаємодії або в зоні видимості.
- [ ] Google Maps — статичне зображення з посиланням або завантаження iframe по кліку.
- [ ] Шрифти (Forum, Manrope, JetBrains Mono з брендбуку): лише потрібні накреслення й кирилиця (`subset`), `font-display: swap`, `preload` для основного; краще — локальні WOFF2 замість Google Fonts.
- [ ] Аналітика (GTM, Pixel) — не блокує рендер; перевіряємо вплив на TBT.

## Сервер і кеш (з фічею 016)

- [ ] Gzip/Brotli для HTML, CSS, JS, SVG.
- [ ] `Cache-Control` на рік для статики з версією в імені файлу; HTML — короткий кеш.
- [ ] HTTP/2 (на LiteSpeed зазвичай уже є).
- [ ] Час відповіді сервера (TTFB) ≤ 600 мс на мобільному — пов'язано з кількістю запитів до БД (`make db-profile`).

## Перевірка

1. `make test-mobile` — усі сторінки з `tests/mobile/pages.txt` (або `URL=/x`). Знімки екрана: `tests/mobile/out/` — переглянути очима.
2. Ручна перевірка на реальному телефоні (Android Chrome + iPhone Safari): меню, кошик, форма заявки, дзвінок, Viber.
3. Перед релізом — PageSpeed Insights (`https://pagespeed.web.dev/`) для головної, категорії й товару на проді: Performance mobile ≥ 90, польові дані CWV «добре».
4. Цифри «до/після» — у `tasks.md` фічі.
