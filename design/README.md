# design/ — макети сайту «Крістал»

Клікабельні HTML-макети нової теми `kristal` за брендбуком (`docs/brandbook/`) і концепцією.
Потрібні, щоб погодити вигляд із клієнтом **до** верстки теми (фіча 003) і сторінок (004–010).
Це не код теми: у прод не деплоїться, OpenCart його не бачить.

## Як подивитися

Відкрити `design/index.html` у браузері — там усі екрани поруч на 390 px і 1280 px.
Окремі сторінки — `design/pages/*.html` (працюють меню, шторка фільтрів, «−/+», калькулятор).

Якщо браузер блокує `file://` (iframe-превʼю порожні), запустити з кореня репозиторію:

```bash
python3 -m http.server 8077   # → http://localhost:8077/design/
```

Шрифти Forum / Manrope / JetBrains Mono підтягуються з Google Fonts через `docs/brandbook/tokens.css` — потрібен інтернет.

## Структура

```
design/
├── index.html          ← огляд усіх екранів
├── README.md
├── build.py            ← збирає pages/ із src/
├── assets/
│   ├── k-design.css    ← стилі (лише токени бренду, класи k-)
│   ├── k-design.js     ← поведінка макетів (−/+, підбір гостей, калькулятор)
│   └── emblem-96.webp, emblem-480.webp   ← емблема, стиснута з docs/brandbook/assets/Logos
├── src/
│   ├── partials/       ← header, footer, lead (форма заявки), icons (SVG-спрайт)
│   └── pages/          ← тіло кожної сторінки
└── pages/              ← ЗГЕНЕРОВАНО, руками не правити
```

Правка: змінити `src/…` або `assets/…` → `python3 design/build.py`.

## Рішення в макетах

- **Mobile-first**, брейкпоінти 768 / 1024 / 1280 (як у `docs/agents/mobile.md`). На 360 px немає горизонтального скролу, кнопки й поля ≥ 44 px, текст ≥ 12 px, телефон — `type="tel"`.
- **Золото** — лише головні кнопки, ціни, активні стани, одне слово в заголовку. **Рубін** — бейдж «Хіт» і банер комплекту в каталозі. Одне сяйво на екран (емблема або головна кнопка).
- **Подвійна золота рамка** (фірмовий прийом) — лише на емблемі в hero і на рекомендованому комплекті.
- **Ціни** — JetBrains Mono, формат `14 ₴ / доба`; знижка за обсяг — зеленим рядком під ціною.
- **Один H1** на сторінку; логотип — не H1 (вимога SEO з концепції).
- **Кошик → бронювання.** Слово «купити» не вживаємо: клієнт додає позиції в кошик події й **бронює** їх передоплатою **50%** (карткою через Fondy або за рахунком для ФОП/ТОВ); решта 50% і доставка — при отриманні. Рішення від 05.11.2026, замінює «заявку без оплати» з концепції — врахувати в специфікації 010.
- Класи з префіксом `k-` (AGENTS.md), кольори/шрифти/відступи — лише `var(--…)` з `tokens.css`.

## Мок і відкриті питання (замінити на реальне)

- Графік роботи (9:00–20:00), «3000+ позицій», «600+ подій на рік», рейтинг 4,9 — вигадані.
- Склад і ціни комплектів «Базовий / Стандарт / Преміум», знижка за 2+ доби, норми калькулятора.
- Відгуки — заглушки з позначкою «приклад», не підписані вигаданими іменами (AGENTS.md §10).
- Чи входить миття посуду в ціну — питання до клієнта (на макетах позначено).
- Що буде з передоплатою, якщо позиції не виявиться на дату (заміна / повернення), і чи є строк повернення передоплати при скасуванні — уточнити в клієнта.
- Фото: потрібна фотосесія складу й подій (темне тло, тепле світло). Іконки — тимчасові, у темі замінити на Phosphor Light.
